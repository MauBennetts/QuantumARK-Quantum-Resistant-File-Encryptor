● Blindaje y Seguridad Militar

🧹 Eliminación de Metadatos Limpia EXIF, GPS, cámara y autor de imágenes.
📏 Ofuscación Signal-style Ruido exponencial variable + jitter OsRng. El tamaño real es imposible de deducir.
🖥️ Pepper de Hardware (KDF) Vincula el archivo a esta máquina física usando su identificador único de hardware.
🎭 Ofuscar Nombre de Salida Renombra el archivo cifrado con 16 bytes hexadecimales aleatorios para máxima privacidad en disco.
⏰ Tiempo de vida limitado (TTL) El archivo se auto-destruirá (no se podrá descifrar) tras la fecha y hora configuradas.
🎭 Modo Duress (Contraseña Señuelo) Cifra un archivo señuelo alternativo. Si se introduce la contraseña señuelo al descifrar, se restaurará el señuelo.
🧩 Fragmentación Reed-Solomon Divide el archivo en fragmentos. Permite recuperar el original si se pierden fragmentos (ej: tolerancia a fallos).
💥 Destrucción Segura del Original (Shredder) Sobrescribe el archivo original en disco antes de borrarlo permanentemente.
